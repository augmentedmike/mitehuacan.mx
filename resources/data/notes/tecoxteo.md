# Tecoxteo corridor — research notes (2026-07-19)

**Operator: "Tehcoxteo"** — mobility company covering the Tehuacán → Coxcatlán →
Teotitlán corridor (the name reads as TEhuacán+COXcatlán+TEOtitlán). Active
Facebook page: https://www.facebook.com/p/Tehcoxteo-100090570908953/

## Stop chain (from the operator's own page)
Tehuacán (base) → San Diego [Chalma] → San Pablo [Tepetzingo] → Santa Cruz
[Acapa] → Y Griega → Altepexi → Ajalpan → **Zinacatepec** → Desviación Axusco →
**Calipan** → **Coxcatlán** → Pueblo Nuevo → San Rafael → Santa Rosa → **Tilapa**
